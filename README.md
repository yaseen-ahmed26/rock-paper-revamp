# Rock Paper Revamped

> **Live Demo:** [Download from Itch.io](https://corporalchicken.itch.io/rpr)
>
> Available for Windows and Linux.

---
### About, Why Revamped?
This is a remake of an [old project](https://github.com/corporal1chicken/rock-paper-scissors-plus) that was poorly made. Hardcoded logic, everything lived in a large match statement, and was very fragile when it came to adding new features.

The goal of the remake was to utilise Godot's Resource system to make a game that is expandable without adding new, or very minimal, lines of code. It is much larger than the old project but also more stable.

---
### Tech
- **Engine**: Godot 4.7

- **Language**: GDScript

---
### Features
Points with an asterisk are brand new and not in the old game.

- **Gameplay Modifiers**: Many of the old modifiers were remade or removed.

- **Gamemodes**: Defines how you win or lose the game.

- ***Save Manager & Profile Screen**: Data now saves locally and displays all stats.

- ***Opponent Types**: Different AI personalities.

- ***Challenges & Tasks**: Preset puzzles and short side goals to do in game.
